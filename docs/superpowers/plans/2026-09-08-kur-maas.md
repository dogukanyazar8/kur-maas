# Kur Maaş Implementation Plan

**Goal:** Deliver a locally runnable salary calculator implementing the confirmed protected-rate policy.
**Architecture:** Pure client calculation, read-only TCMB API, no salary persistence.
**Tech Stack:** Next.js 16.3.4, React 19.2.8, TypeScript 6.0.3, decimal.js 10.6.0, Vitest 5.0.0, Playwright 1.63.0, Node 24.20.0 LTS.
**Spec:** `docs/design.md`

## Global constraints

- Preserve the confirmed formula and negative-rate protection.
- TCMB USD ForexBuying only; official and scenario results remain visibly distinct.
- Decimal input/JSON strings, explicit locales, date-only periods, no salary in HTTP requests or storage.
- Small focused modules, exact dependencies, no deployment or commit.
